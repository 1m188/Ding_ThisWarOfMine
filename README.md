# Ding_ThisWarOfMine

Steam 游戏：《This War of Mine》（这是我的战争）修改器

## 功能

- **无限生命**：居民受到的伤害会被直接免掉。开启的是游戏自带的防弹模式，只保护居民，敌人不受影响。
- **无限背包空间**：角色背包容量固定为 300 格。界面显示的格数和实际能放的数量都按 300 算。
- **工具无限耐久度**：刀、斧、锯等有耐久度的物品不再损耗。只挡耐久扣减，开锁器等一次性消耗品没有耐久，不受影响。
- **瞬间制作物品**：制作、建造、升级开始后立刻完成，不用等进度条。三类工序共用同一段计时逻辑，会一起生效。
- **锁定白天时间**：白天时钟停止，不再前进。但只冻结进度，不碰天数记录。
- **锁定晚上时间**：夜晚时钟停止，可以一直搜刮到自己决定回营。它只停显示时钟，夜晚的搜刮结算和回营流程照常进行。
- **一击必杀**：任何伤害都直接让目标死亡。对所有角色生效，包括自己人；想保护居民就同时开启无限生命。
- **制作不消耗资源**：制作、建造、升级不扣材料，材料不足也能开工，功能语义上和无限资源差不多。
- **游戏倍速**：加快游戏速度。它改的是全局时间基准，动作、制作进度和昼夜时钟一起变快。

每项修改器功能的原理和实现见 [docs/](docs/)，部分附风灵月影实现对照。

## 使用

- 启动游戏后运行 `TwomTrainer.exe`；先开修改器也可以，它会自动等待并连接游戏。
- 打开 NumLock，用数字小键盘切换功能；窗口实时显示连接状态和每项功能的状态。
- Ctrl+C 或关闭窗口退出，已开启的功能会先还原；游戏退出后功能状态自动复位。

## 构建

需要 Windows x64、.NET 10 SDK；NativeAOT 发布还需要 MSVC 生成工具。

- `build.ps1`：编译。
- `publish.ps1`：发布 win-x64 单文件 `TwomTrainer.exe` 到 `TwomTrainer/TwomTrainer.Cli/bin/Release/net10.0/win-x64/publish/`。

## 注意

- 只支持 v6.0.0：补丁偏移按这个版本写死，其它版本不要使用；字节对不上时功能会拒绝开启，不会强行写入。
- 游戏用管理员身份启动时，修改器也要用管理员身份启动。
- 随附[风灵月影修改器](./This%20War%20of%20Mine%20v6.0.0%20Plus%208%20Trainer.exe) ，支持无限生命、无限背包空间、工具无限耐久度、瞬间制作物品、锁定白天时间、锁定晚上时间、设置游戏速度、一击必杀等功能。
